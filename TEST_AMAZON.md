## 🚀 How to Test

### 1. Reload Your Extension

1. Go to `chrome://extensions/`
2. Click the **reload button** on Harmony extension
3. Extension is now updated!

### 2. Test on Amazon

1. **Go to amazon.com**
2. **Add an item to your cart** (any item)
3. **Click "Cart"** (top right)
4. **Look for the Harmony overlay** (bottom-right corner)

### 3. What You Should See

✅ **Merchant:** "Amazon"  
✅ **Amount:** Your cart total OR "Check page" if not detected  
✅ **Best Card:** Recommendation based on category  
✅ **Rewards:** How much you'd earn with that card

## 🎯 Debug If Not Showing

### Open Browser Console

1. **Press F12** on the Amazon cart page
2. **Click "Console"** tab
3. **Look for these messages:**

✅ **Good:**
```
✓ Harmony: Transaction detected
✓ Harmony: Recommendation generated
```

❌ **If you see errors:**
- Check that extension is enabled
- Check that you're on amazon.com
- Refresh the page
